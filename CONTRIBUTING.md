# Como contribuir

Obrigado pelo interesse em contribuir com o projeto!

## Primeiros passos

1. Faça um fork do repositório.
2. Clone seu fork: `git clone https://github.com/rissveil/farmdeorbs.git`
3. Crie uma branch para sua alteração: `git checkout -b feature/nova-funcionalidade`
4. Faça as alterações necessárias.
5. Registre as mudanças: `git commit -m "Adiciona nova funcionalidade"`
6. Envie a branch para seu fork: `git push origin feature/nova-funcionalidade`
7. Abra um Pull Request.

## Estilo do código

- Siga o guia de estilo PEP 8 para Python.
- Use nomes claros para variáveis e funções.
- Adicione docstrings às funções e classes quando forem úteis.
- Mantenha cada função focada em uma responsabilidade.
- Comente trechos complexos, evitando comentários que apenas repetem o código.

## Mensagens de commit

- Escreva mensagens claras e descritivas.
- Comece com letra maiúscula.
- Prefira verbos no imperativo, como “Adiciona recurso”.
- Referencie issues quando fizer sentido.

## Processo de Pull Request

1. Verifique se o código funciona corretamente.
2. Atualize a documentação quando necessário.
3. Teste em diferentes ambientes, se possível.
4. Confira se não há erros de lint.
5. Explique claramente as mudanças na descrição do Pull Request.

## Relatar problemas

Ao abrir uma issue, inclua, sempre que possível:

- Descrição do problema.
- Etapas para reproduzi-lo.
- Comportamento esperado e comportamento observado.
- Sistema operacional e versão do Python.
- Mensagens de erro relevantes.

Dúvidas e sugestões também são bem-vindas por meio das issues.

Obrigado por contribuir!
