# Obrigado por usar o farmorbs

## Como começar

1. Faça um fork do repositório.
2. Clone seu fork:
   `git clone https://github.com/Rissa/farm-de-orbs.git`
3. Crie uma nova branch:
   `git checkout -b recurso/novo-jogo`
4. Faça suas alterações.
5. Registre as alterações:
   `git commit -m "Adiciona suporte a novo jogo"`
6. Envie a branch:
   `git push origin recurso/novo-jogo`
7. Abra uma solicitação de alteração no GitHub.

## Estilo do código

- Siga o padrão PEP 8 do Python.
- Use nomes claros para variáveis e funções.
- Adicione documentação às funções e classes quando necessário.
- Mantenha cada função com uma responsabilidade bem definida.
- Comente apenas a lógica que realmente precise de explicação.

## Mensagens de alteração

- Use mensagens claras e descritivas.
- Comece com letra maiúscula.
- Escreva no presente, por exemplo: `Adiciona suporte` em vez de `Adicionado suporte`.
- Referencie problemas ou solicitações quando necessário.

## Solicitações de alteração

Antes de enviar uma alteração:

1. Verifique se o projeto funciona corretamente.
2. Atualize a documentação quando necessário.
3. Teste em diferentes ambientes quando possível.
4. Verifique se não existem erros de análise ou estilo.
5. Explique claramente o que foi alterado.

## Relatando problemas

Ao relatar um problema, informe:

- Descrição do problema.
- Passos para reproduzir.
- Comportamento esperado.
- Comportamento observado.
- Sistema operacional e versão do Python.
- Mensagens de erro.

## Dúvidas

Abra uma solicitação no GitHub para dúvidas, sugestões ou discussões relacionadas ao projeto.
